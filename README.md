# Estrutura-de-Dados-avancada-em-C

Esta seção de branchs é para cada código de exemplo que eu fiz para demonstrar a construção de estruturas de dados mais elaboradas, como Listas. Nela se encontrar listas circulares, listas duplamente encadeadas, listas circulares duplamente encadeadas, uso de no descritor, no encadeado... Em cada branch tem um exemplo de uma dessas estruturas.
Além disso, temos também uma branch para demonstrar a construção de uma busca binária em c.
